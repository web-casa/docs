Web.Casa 通过 Docker 容器提供 **MySQL** 和 **MariaDB** 的完整生命周期管理。从创建实例到配置调优，均可在面板中完成。

## 实例管理

每个 MySQL/MariaDB 实例以**独立的 Docker 容器**运行，支持同时管理多个实例。

### 创建实例

1. 进入 **数据库** 页面，点击 **创建实例**。
2. 选择引擎：**MySQL** 或 **MariaDB**。
3. 配置实例名称和 root 密码。
4. 可选择 **预设**（开发环境 / 生产环境）。
5. 点击 **创建** 启动容器。

### 实例操作

| 操作 | 说明 |
|------|------|
| **启动** | 启动容器并接受连接 |
| **停止** | 优雅关闭实例 |
| **删除** | 移除容器及所有关联数据 |

> 删除实例是**不可逆操作**，请在删除前备份数据库。

## 连接信息

每个实例提供多种格式的连接信息，开箱即用：

- **CLI 命令** -- 复制到终端即可连接
- **连接 URI** -- `mysql://user:password@host:port/dbname`，适用于应用配置
- **环境变量** -- `DATABASE_URL=...`，适用于 `.env` 文件
- **Docker 内部地址** -- 用于同一 Docker 网络内的服务互联

## 数据库操作

### 创建数据库

1. 打开 MySQL/MariaDB 实例。
2. 进入 **数据库** 选项卡，点击 **创建数据库**。
3. 输入数据库名称。
4. 选择 **字符集**（默认：`utf8mb4`）和 **排序规则**。
5. 点击 **创建**。

### 删除数据库

在列表中选择目标数据库，点击 **删除**，在弹窗中确认操作。

> 删除数据库会永久移除其中所有表和数据。

## 用户管理

### 创建用户

1. 进入 **用户** 选项卡，点击 **创建用户**。
2. 设置 **用户名** 和 **密码**。
3. 点击 **创建**。

### 授权数据库访问

创建用户后，为其授予一个或多个数据库的访问权限：

1. 在列表中选择目标用户。
2. 选择要授权的数据库。
3. 点击 **授权访问**。

### 删除用户

选择用户并点击 **删除**，将移除该用户及其所有关联权限。

## 查询控制台

内置的 **SQL 控制台** 支持直接在浏览器中对任意实例执行查询：

- 编写并执行 **SQL 语句**，结果以表格形式展示
- 通过下拉菜单切换实例和数据库
- 查看查询执行时间和返回行数

> 查询控制台适用于 Web.Casa 管理的所有 MySQL 和 MariaDB 实例。

## 高级配置

通过 **设置** 选项卡调优实例性能。也可以先应用 **开发环境** 或 **生产环境** 预设作为基础。

| 参数 | 说明 | 默认值（开发） |
|------|------|----------------|
| **InnoDB 缓冲池大小** | 分配给 InnoDB 缓存的内存 | 128 MB |
| **最大连接数** | 允许的最大同时连接数 | 151 |
| **字符集** | 新数据库的默认字符集 | `utf8mb4` |
| **排序规则** | 字符串比较的默认排序规则 | `utf8mb4_general_ci` |
| **慢查询日志** | 记录超过时间阈值的查询 | 已禁用 |

> **生产环境预设** 会增大缓冲池和最大连接数以提高吞吐量。**开发环境预设** 使用较低的资源限制，适合本地开发。
