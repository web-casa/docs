Web.Casa 通过 Docker 容器提供 **Redis** 的完整生命周期管理。从创建实例到配置调优，均可在面板中完成。

## 实例管理

每个 Redis 实例以**独立的 Docker 容器**运行。

### 创建实例

1. 进入 **数据库** 页面，点击 **创建实例**。
2. 选择 **Redis** 作为引擎。
3. 配置实例名称和可选的认证密码。
4. 可选择 **预设**（开发环境 / 生产环境）。
5. 点击 **创建** 启动容器。

### 实例操作

| 操作 | 说明 |
|------|------|
| **启动** | 启动容器并接受连接 |
| **停止** | 优雅关闭实例 |
| **删除** | 移除容器及所有关联数据 |

> 删除实例是**不可逆操作**，如果持久化数据重要，请确保已备份。

## 连接信息

每个实例提供多种格式的连接信息，开箱即用：

- **CLI 命令** -- 可直接粘贴到终端的 `redis-cli` 命令
- **连接 URI** -- `redis://:password@host:port`，适用于应用配置
- **环境变量** -- `REDIS_URL=...`，适用于 `.env` 文件
- **Docker 内部地址** -- 用于同一 Docker 网络内的服务互联

## 命令控制台

内置的 **命令控制台** 支持直接在浏览器中对任意 Redis 实例执行命令：

- 执行只读 Redis 命令（`GET`、`KEYS`、`INFO`、`TTL`、`TYPE`、`EXISTS`、`DBSIZE`、`MGET`、`HGETALL`、`LRANGE`、`SCARD`、`SMEMBERS`、`ZRANGE`）
- 以格式化方式查看所有数据类型的响应
- 通过下拉菜单切换实例

> 命令控制台为**只读模式** — 仅允许上述列出的命令。`SET` 等写入命令会被阻止。
>
> 命令控制台适用于 Web.Casa 管理的所有 Redis 实例。

## 日志

查看容器输出的实时 **实例日志**。适用于调试连接问题、监控慢操作和验证配置变更。

## 高级配置

通过 **设置** 选项卡调优实例行为。也可以先应用 **开发环境** 或 **生产环境** 预设作为基础。

### 内存与淘汰策略

| 参数 | 说明 |
|------|------|
| **最大内存** | 实例的内存上限 |
| **淘汰策略** | 达到内存上限时的处理行为（详见下表） |

**可用的淘汰策略：**

| 策略 | 行为 |
|------|------|
| `noeviction` | 内存达到上限时返回错误（不移除任何键） |
| `allkeys-lru` | 从**所有键**中移除最近最少使用的键 |
| `volatile-lru` | 从**设置了过期时间的键**中移除最近最少使用的键 |
| `allkeys-random` | 从**所有键**中随机移除键 |
| `volatile-ttl` | 优先移除 **TTL 最短**的键 |

### 持久化

| 参数 | 说明 |
|------|------|
| **AOF 持久化** | 追加写入文件 -- 记录每次写操作，保证数据持久性 |
| **RDB 快照** | 按配置间隔生成时间点快照 |

- **AOF** 提供更强的持久性保证（最多丢失一秒数据）
- **RDB** 提供紧凑的快照和更快的重启速度
- 两者可以同时启用，获得最大安全保障

> **生产环境预设** 启用 AOF 持久化并设置更高的内存上限。**开发环境预设** 使用最低资源配置，持久化默认关闭。
