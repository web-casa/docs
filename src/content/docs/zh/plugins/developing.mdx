你可以通过开发自定义插件来扩展 Web.Casa。插件是一个实现 **Plugin 接口**的 Go 包，编译到 Web.Casa 二进制文件中。

## 前提条件

- **Go**（版本需与 Web.Casa 的 go.mod 一致）
- 熟悉 **Gin** Web 框架（用于路由）
- **React**（用于前端组件）
- 了解[插件系统](/zh/plugins/plugin-system/)架构

## 项目结构

在 `plugins/`（项目根目录）下创建以插件名命名的目录：

```
plugins/myplugin/
  myplugin.go       # 插件结构体和生命周期方法
  handler.go        # HTTP 处理器
  service.go        # 业务逻辑
  model.go          # 数据库模型
```

## 实现 Plugin 接口

插件结构体必须实现以下生命周期方法：

```go
type MyPlugin struct {
    ctx *plugin.Context
    db  *gorm.DB
}

func (p *MyPlugin) Metadata() plugin.Metadata {
    return plugin.Metadata{
        Name:         "myplugin",
        Version:      "1.0.0",
        Description:  "我的自定义插件",
        Dependencies: []string{"docker"}, // 可选
    }
}

func (p *MyPlugin) Init(ctx *plugin.Context) error {
    p.ctx = ctx
    p.db = ctx.DB
    // 自动迁移数据库表
    // 注册事件订阅
    return nil
}

func (p *MyPlugin) Start() error {
    // 启动后台进程
    return nil
}

func (p *MyPlugin) Stop() error {
    // 清理关闭
    return nil
}
```

## 注册路由

使用 CoreAPI 提供的 **Gin 路由组**注册路由。路由挂载在 `/api/plugins/<plugin-name>/` 路径下：

```go
func (p *MyPlugin) RegisterRoutes(group *gin.RouterGroup) {
    group.GET("/items", p.handleListItems)
    group.POST("/items", p.handleCreateItem)
    group.GET("/items/:id", p.handleGetItem)
    group.PUT("/items/:id", p.handleUpdateItem)
    group.DELETE("/items/:id", p.handleDeleteItem)
}
```

认证和授权中间件会自动应用到插件路由。

## 事件总线

### 发布事件

在操作完成时通知其他插件：

```go
p.ctx.EventBus.Publish("myplugin.item.created", map[string]interface{}{
    "id":   item.ID,
    "name": item.Name,
})
```

### 订阅事件

响应其他插件或核心系统的事件：

```go
p.ctx.EventBus.Subscribe("container.started", func(e plugin.Event) {
    // 处理容器启动事件
})
```

**常用事件订阅：**

| 事件 | 来源 | 负载 |
|------|------|------|
| `container.started` | Docker 插件 | 容器 ID、名称 |
| `container.stopped` | Docker 插件 | 容器 ID、名称 |
| `host.created` | 反向代理 | 站点 ID、域名 |
| `backup.completed` | 备份插件 | 备份 ID、大小 |
| `project.deployed` | 部署插件 | 项目 ID、状态 |

## ConfigStore

使用 **ConfigStore** 持久化插件设置，无需直接访问数据库：

```go
// 写入设置
p.ctx.ConfigStore.Set("myplugin", "api_url", "https://example.com")

// 读取设置
value := p.ctx.ConfigStore.Get("myplugin", "api_url")
```

存储在 ConfigStore 中的设置会自动在 Web.Casa 设置界面中显示，供用户配置。

## 插件 Context 参考

插件 Context 提供对共享系统服务的访问：

| 服务 | 访问方法 | 用途 |
|------|---------|------|
| **数据库** | `ctx.DB` | GORM 数据库连接 |
| **事件总线** | `ctx.EventBus` | 发布和订阅事件 |
| **ConfigStore** | `ctx.ConfigStore` | 作用域键值设置 |
| **日志记录器** | `ctx.Logger` | 结构化日志 |

## 注册插件

开发完成后，在插件加载器中注册插件，使 Web.Casa 在启动时发现它：

```go
// 在插件注册文件中
pluginManager.Register(&myplugin.MyPlugin{})
```
