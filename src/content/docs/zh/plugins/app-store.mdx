---
title: 应用商店
description: 一键安装 Docker 应用，支持自定义应用源和项目模板
---

应用商店让你**浏览、安装和管理 Docker 应用**，只需单击即可完成，无需手动编写 Compose 文件或使用命令行。

## 浏览应用

应用目录按**分类**组织，方便发现：

- CMS 和博客平台
- 开发工具
- 媒体服务器
- 监控和可观测性
- 数据库和管理工具
- 通信和协作
- 更多分类

使用**搜索栏**按名称或关键词查找特定应用。

## 安装应用

1. 浏览或搜索目录，选择目标应用
2. 点击**安装**
3. 配置安装选项：

| 设置 | 说明 |
|------|------|
| **实例名称** | 用于标识此安装的唯一名称 |
| **域名**（可选） | 为应用分配域名 — Web.Casa **自动创建反向代理** |
| **自动更新** | 新版本可用时自动更新镜像 |
| **环境变量** | 自定义应用特定设置（密码、端口等） |

4. 确认安装
5. Web.Casa 拉取 Docker 镜像、创建网络和卷、启动容器

安装进度实时显示。

> **警告：** 部分应用需要**特权模式**或提升的权限。应用商店会在安装前显示安全警告。请仔细审查权限后再继续。

## 应用源

应用商店支持多个应用模板来源：

- **官方源** — Web.Casa 维护的精选应用
- **自定义 Git 仓库** — 添加包含应用定义的自有 Git 仓库
- **同步** — 手动触发同步以从所有源获取最新应用定义

### 添加自定义源

1. 进入应用商店设置
2. 添加 Git 仓库 URL
3. 同步源以导入其应用

## 我的应用

**我的应用**显示所有已安装应用及其状态。

在此视图中，你可以：

- **启动 / 停止 / 重启**应用
- **更新**到最新镜像版本（数据卷保持不变）
- **卸载**应用（移除容器和网络；数据卷可选择保留）
- 查看容器日志和资源使用情况

## 项目模板

除 Docker 应用外，应用商店还提供**项目模板**用于启动新的开发项目：

- 常用框架和技术栈的预构建模板
- **框架过滤器**按技术筛选（Node.js、Python、Go、PHP 等）
- 模板包含推荐的项目结构、Dockerfile 和部署配置

1. 浏览模板并选择一个
2. 自定义项目名称和设置
3. 模板被脚手架为一个新项目，随时可以部署

## 自动反向代理

安装时提供**域名**后，Web.Casa 自动：

1. 创建指向应用容器的反向代理站点
2. 配置 TLS/SSL（如适用）
3. 使应用通过指定域名可访问

这省去了安装应用后手动配置反向代理规则的步骤。
