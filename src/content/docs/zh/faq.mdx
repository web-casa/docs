## Web.Casa 是什么？与 Nginx Proxy Manager 有什么区别？

Web.Casa 是基于 **Caddy**（非 Nginx）构建的现代化服务器管理面板。与 Nginx Proxy Manager 不同，它内置了 AI 助手、插件系统以及 Docker、数据库和项目部署管理功能，集成于一个平台中。

- 通过 Caddy 零配置自动 HTTPS
- AI 驱动的错误诊断与 Docker Compose 生成
- 可扩展的插件架构（12+ 插件）
- 内置 Docker、数据库、文件管理器和部署工具

## 支持哪些 Linux 发行版？

Web.Casa 仅支持 EL9/EL10（RHEL 系）发行版。**不支持** Debian/Ubuntu（deb 系）发行版。

- **AlmaLinux** 9+
- **Rocky Linux** 9+
- **CentOS Stream** 9+
- **RHEL** 9+
- **Oracle Linux** 9+
- **Fedora** 41+
- **openEuler**
- **openCloudOS**
- **银河麒麟**（Kylin）

支持 `amd64` 和 `arm64` 两种架构。

## 不安装 Docker 能使用 Web.Casa 吗？

可以。Docker 是可选的。安装时使用 `--no-docker` 参数可跳过 Docker 安装。核心反向代理、SSL 管理和静态托管功能无需 Docker 即可运行。依赖 Docker 的功能（容器管理、Compose 编排、应用商店）将不可用。

## 如何修改默认端口？

在配置文件中设置 `WEBCASA_PORT` 环境变量，或在安装时传入 `--port` 参数：

```bash
# 安装时指定
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | bash -s -- --port 9090

# 安装后修改配置文件
sudo nano /etc/webcasa/webcasa.env
# 设置: WEBCASA_PORT=9090
sudo systemctl restart webcasa
```

## 如何启用泛域名证书？

泛域名证书需要 DNS Challenge 验证。在主机设置中配置受支持的 DNS 提供商（Cloudflare、AliDNS、腾讯云 DNS 或 Route53），然后选择 **泛域名** TLS 模式。

1. 进入 **反向代理** > **主机** > 编辑主机
2. 在 TLS 设置中选择 **DNS Challenge**
3. 选择 DNS 提供商并输入 API 凭证
4. 启用 `*.yourdomain.com` 泛域名选项

## 如何备份与还原？

备份插件使用 Kopia 作为备份引擎，支持多种存储目标：

- **本地**文件系统
- **S3** 兼容对象存储
- **WebDAV** 服务器
- **SFTP** 远程主机

通过 Cron 表达式配置备份计划，设置保留策略自动管理备份历史。通过 Web 界面从任意快照还原。

## 支持多用户访问吗？

支持。Web.Casa 提供基于角色的访问控制（RBAC），内置两种角色：

- **管理员** — 拥有所有功能和设置的完整访问权限
- **查看者** — 仅可只读访问仪表盘和日志

所有用户操作均记录在审计日志中，确保可追溯性。

## AI 助手支持哪些 LLM 提供商？

AI 助手原生支持 **OpenAI**、**Anthropic**（Claude）和 **Google Generative AI**（Gemini）API，以及 **DeepSeek**、**Moonshot/Kimi** 和 **智谱/GLM**。任何兼容 OpenAI 的端点（Azure OpenAI、Ollama 等）同样适用。在 **设置 > AI 助手** 中配置供应商、API 端点和密钥。API 密钥使用 AES-256-GCM 加密存储。

## 如何与 Claude Code / Cursor 集成？

Web.Casa 内置 MCP Server 插件，提供 44 个工具用于 IDE 集成：

1. 在设置中启用 **MCP Server** 插件
2. 在 **设置 > API Token** 中生成 API 令牌（以 `wc_` 为前缀）
3. 在 IDE 中配置 MCP 端点：

```json
{
  "mcpServers": {
    "webcasa": {
      "url": "https://your-server:port/api/plugins/mcpserver/mcp",
      "headers": {
        "Authorization": "Bearer wc_your_token_here"
      }
    }
  }
}
```

兼容 Cursor、Windsurf 和 Claude Code。

## Web.Casa 可以用于生产环境吗？

可以。Web.Casa v0.9.3 已发布，包含全面的安全加固：JWT 鉴权、RBAC 授权、路径穿越防护、CORS 严格匹配以及 WebSocket Origin 校验。项目采用 MIT 许可证，已在生产环境中使用。

## 如何升级？

使用安装脚本的 `--upgrade` 参数：

```bash
# 标准升级（下载预编译二进制）
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | bash -s -- --upgrade

# 从源码升级（本地编译）
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | bash -s -- --upgrade-from-source
```

升级过程中您的配置和数据会被保留。

## 如何卸载？

安装脚本支持两种卸载模式：

```bash
# 常规卸载（移除程序和服务，保留数据）
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | bash -s -- --uninstall

# 完全清除（移除所有内容，包括数据和配置）
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | bash -s -- --purge
```

`--purge` 选项会删除 `/etc/webcasa/` 下的所有数据以及 systemd 服务文件。
