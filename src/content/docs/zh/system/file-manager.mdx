title: 文件管理
description: Web 文件浏览器，支持上传、下载、在线编辑和压缩/解压
---

文件管理器提供基于浏览器的**文件管理界面**，无需 SSH 或 FTP 即可直接操作服务器文件系统。

## 文件浏览

使用类似桌面资源管理器的界面浏览服务器文件：

- **目录导航** — 点击文件夹进入，使用面包屑栏跳转到父目录，或直接输入路径
- **文件详情** — 每个条目显示名称、大小、权限、所有者和最后修改时间
- **批量选择** — 选择多个文件和文件夹执行批量操作

## 文件操作

| 操作 | 说明 |
|------|------|
| **创建文件夹** | 在任意路径创建新目录 |
| **重命名** | 内联重命名文件和文件夹 |
| **上传** | 拖拽或文件选择器上传，支持多文件同时上传并显示进度 |
| **下载** | 单击下载单个文件 |
| **删除** | 删除文件和目录（需确认） |
| **设置权限** | 使用 chmod 修改文件权限（如 `755`、`644`） |

## 内置编辑器

在浏览器中直接编辑文件，支持常见格式的**语法高亮**：

- 配置文件（`.conf`、`.ini`、`.env`、`.toml`、`.yaml`）
- Web 文件（HTML、CSS、JavaScript）
- Shell 脚本、Go、Python、PHP
- JSON、XML

> **提示：** 内置编辑器适合快速修改配置文件。对于较大的编辑任务，建议使用网页终端配合你喜欢的编辑器（`vim`、`nano`）。

## 压缩与解压

文件管理器支持创建和解压归档文件：

### 创建归档
1. 选择一个或多个文件或目录
2. 选择**压缩**
3. 选中的文件被打包为归档文件

### 解压归档
1. 选择一个压缩文件
2. 选择**解压**
3. 内容被解压到目标目录

> **注意：** 文件管理器遵循 Linux 文件权限。Web.Casa 进程用户无法执行的操作会返回相应的错误信息。请确认进程用户对目标路径具有必要的读写权限。
