Web.Casa 内置**网页终端**，让你在浏览器中直接访问服务器命令行，无需 SSH 客户端。

## 核心功能

- 基于 **xterm.js** 构建，完整支持 ANSI 颜色、Unicode 和鼠标事件
- 连接到服务器上的真实 **PTY**（伪终端）
- `vim`、`htop`、`top`、`nano` 等交互式程序可正常运行
- 支持标准键盘快捷键进行**复制粘贴**
- 鼠标选择文本即可复制

## 多标签页

同时打开**多个 Shell 会话**，每个标签页独立运行：

- 每个标签页拥有独立的工作目录、Shell 历史和运行进程
- 创建新标签页执行并行任务
- 标签页之间即时切换
- 新标签页使用系统默认 Shell

**示例工作流：**
- **标签 1** — 使用 `tail -f` 监控日志
- **标签 2** — 编辑配置文件
- **标签 3** — 执行部署命令

## 窗口控制

- **全屏展开**终端以获得最大工作空间
- **恢复**为默认面板大小
- 终端会**动态调整大小**以适应浏览器窗口 — PTY 尺寸自动同步

## 连接方式

- 会话通过 **WebSocket** 传输，延迟低、交互实时
- WebSocket 连接断开时自动重连
- 所有输入输出通过服务端 PTY 处理，确保终端仿真准确

## 常见用途

1. **快速管理** — 无需打开 SSH 客户端即可运行一次性命令
2. **日志查看** — `tail -f /var/log/syslog` 或 `docker logs -f <容器名>`
3. **问题排查** — 需要直接 Shell 访问时进行调试
4. **服务管理** — 重启服务、检查进程状态、查看配置

> **提示：** 使用多标签页可以在一个标签页中保持日志监控，同时在另一个标签页中工作，避免中断长时间运行的进程。
