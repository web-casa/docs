Web.Casa 提供**实时系统监控**，通过 WebSocket 将指标数据推送到浏览器，无需轮询，延迟极低。

## 仪表盘指标

监控仪表盘实时展示以下指标：

| 指标 | 详情 |
|------|------|
| **CPU** | 各核心使用率、总体使用百分比、负载均值 |
| **内存** | 总量、已用、可用、缓存；消耗明细 |
| **Swap** | 交换空间使用情况 |
| **磁盘** | 各挂载点的容量和可用空间 |
| **磁盘 I/O** | 读写吞吐量（字节/秒） |
| **网络 I/O** | 各网卡的发送/接收流量 |
| **负载均值** | 1 分钟、5 分钟、15 分钟平均负载 |

## 容器指标

针对每个运行中的 **Docker 容器**，监控插件会采集：

- 每个容器的 **CPU 使用率**
- 每个容器的 **内存占用**
- 每个容器的 **网络 I/O**（发送/接收）

帮助你快速定位资源消耗异常的容器。

## 历史图表

指标数据会被保留，支持多个时间范围查看：

- **1 小时** — 细粒度、秒级分辨率
- **6 小时** — 短期趋势分析
- **24 小时** — 日常模式和峰值检测
- **7 天** — 每周使用趋势
- **30 天** — 长期容量规划

图表支持缩放和平移操作，方便检查特定时间窗口。

## WebSocket 实时连接

监控数据通过 **WebSocket** 推送，具备以下优势：

- **低延迟更新** — 指标实时到达，无需重复 HTTP 请求
- **高效传输** — 单个持久连接替代持续轮询
- **流畅渲染** — 浏览器以极低延迟绘制实时图表

## 告警规则

当指标超过设定阈值时，系统会触发告警通知。

### 配置告警

每条告警规则包含以下参数：

1. **指标** — 监控的指标（CPU、内存、磁盘、网络、负载均值、Swap）
2. **运算符** — 比较方式（大于、小于、等于）
3. **阈值** — 触发告警的数值
4. **持续时间** — 条件需持续多长时间才触发（例如 5 分钟）
5. **冷却时间** — 同一规则重复告警的最小间隔

> **提示：** 设置冷却时间可以避免告警疲劳。例如，设置 15 分钟冷却可以防止 CPU 告警在持续高负载期间每分钟重复触发。

### 通知渠道

告警可通过以下渠道发送：

| 渠道 | 用途 |
|------|------|
| **Discord** | 通过 Webhook 发送到团队聊天 |
| **Telegram** | 通过 Bot 发送到聊天或群组 |
| **Webhook** | 自定义 HTTP 端点，可集成任意系统 |

### 告警历史

所有已触发的告警会记录在**告警历史**中，显示：

- 触发的规则
- 触发时的指标值
- 时间戳
- 通知发送状态

> **注意：** 监控功能需要启用监控插件。如果看不到监控数据，请在**插件**设置中确认插件已激活。
