---
title: 审计日志
description: 记录所有操作的动作类型、目标、详情、IP 地址、时间和用户信息
---

Web.Casa 内置**审计日志**系统，自动记录面板中执行的每一个重要操作。审计日志提供责任追踪、操作溯源和安全监控能力。

## 记录范围

每个创建、修改或删除资源的操作都会生成一条日志，包括：

- **用户管理** -- 账户创建、角色变更、密码重置、账户删除
- **主机操作** -- 创建、更新、删除反向代理主机
- **DNS 提供商变更** -- 添加、编辑、移除 DNS 提供商
- **证书操作** -- 签发、续期、吊销证书
- **Docker 操作** -- 容器启动、停止、重启、移除
- **数据库操作** -- 创建、删除数据库和数据库用户
- **备份与恢复** -- 创建备份、执行恢复
- **防火墙变更** -- 规则添加、修改、移除
- **系统设置** -- 配置变更、Caddy 重载
- **认证事件** -- 登录成功、登录失败、双因素认证事件

## 日志条目字段

每条审计日志包含以下字段：

| 字段 | 说明 |
|------|------|
| **动作（Action）** | 执行的操作类型（如 `create`、`update`、`delete`、`login`） |
| **目标（Target）** | 受操作影响的资源或实体 |
| **详情（Detail）** | 操作的附加上下文信息 |
| **IP 地址** | 执行操作的用户来源 IP 地址 |
| **时间（Time）** | 操作发生的时间戳 |
| **用户（User）** | 执行操作的账户用户名 |

## 查看与筛选

面板中的审计日志界面提供：

- **按动作类型筛选** -- 缩小结果范围到特定操作（如仅查看 `delete` 操作）
- **总数显示** -- 显示匹配日志条目的总数
- **时间排序** -- 条目按时间倒序排列
- **分页浏览** -- 浏览大量日志记录

## 访问权限

- **管理员**用户可以查看完整的审计日志
- **查看者**用户可以以只读模式查看审计日志
- 审计日志条目**不能通过面板界面修改或删除**

## 存储位置

审计日志存储在 **SQLite 数据库**中，位于 `/var/lib/webcasa/webcasa.db`，与其他面板数据一起存储。使用面板的导出功能时，审计日志会被包含在导出数据中。

> **提示：** 对于有合规要求的环境，建议定期导出审计日志进行存档。使用**设置 > 导出**创建包含审计数据的完整备份。
