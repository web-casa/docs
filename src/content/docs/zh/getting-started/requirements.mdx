Web.Casa 运行在 **systemd** 管理的 Linux 服务器上。安装前请确认以下要求。

> 暂不支持 Windows 和 macOS 作为生产部署平台。

## 支持的操作系统

Web.Casa 仅支持 **EL9/EL10**（RHEL 系）发行版。不支持 Debian 系（Ubuntu、Debian）。

| 发行版 | 最低版本 |
|--------|---------|
| **RHEL** | 9+ |
| **AlmaLinux** | 9+ |
| **Rocky Linux** | 9+ |
| **CentOS Stream** | 9+ |
| **Oracle Linux** | 9+ |
| **Fedora** | 38+ |
| **openAnolis** | 9+ |
| **阿里云 Linux** | 3+ |
| **openEuler** | 所有支持版本 |
| **openCloudOS** | 9+ |
| **银河麒麟**（Kylin） | 所有支持版本 |

**支持架构：** **x86_64**（amd64）和 **aarch64**（arm64）。

## 硬件配置

| 资源 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **CPU** | 1 核 | 2 核及以上 |
| **内存** | **512 MB** | **1 GB+**（运行容器、数据库或 AI 功能时建议更高） |
| **磁盘** | **1 GB** 可用空间 | **10 GB+**（用于面板、日志、备份和容器镜像） |

## 网络与端口

以下端口需在服务器防火墙和云安全组中放行：

| 端口 | 服务 | 是否必须 |
|------|------|---------|
| **39921** | Web.Casa 管理面板 | 是 |
| **80** | Caddy HTTP 流量 | 是（用于 HTTPS 证书签发） |
| **443** | Caddy HTTPS 流量 | 是 |
| **22** | SSH | 建议保留（配置防火墙插件时注意不要锁定自己） |

> 服务器需要 **公网 IP** 才能通过 Let's Encrypt 自动签发 HTTPS 证书。启用 HTTPS 前，请确保域名的 DNS A/AAAA 记录已指向服务器 IP。

## 可选依赖

### Docker 功能

运行 Web.Casa 面板本身 **不需要** Docker，但以下功能依赖 Docker：

- 容器管理
- Compose 编排
- 应用商店安装
- 数据库管理（MySQL、PostgreSQL、MariaDB、Redis 以容器方式运行）

> Docker Engine 可以直接通过 Web.Casa 面板安装，无需手动配置。

### 源码编译

如果需要从源码编译 Web.Casa 而非使用安装脚本，需要以下工具：

- **Go 1.26+**
- **Node.js 24+**
- **GCC**（用于 CGo / SQLite 编译）

### DNS 提供商凭据

仅在使用 **DNS 验证签发通配符证书** 时需要。支持的提供商：

- Cloudflare
- 阿里云 DNS（AliDNS）
- 腾讯云 DNS（DNSPod）
- Amazon Route53
