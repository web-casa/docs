---
title: 快速上手
description: 首次登录 Web.Casa、完成初始设置并创建第一个反向代理站点
---

完成 [安装](/zh/getting-started/installation/) 后，按以下步骤开始使用。

## 第一步：访问面板

在浏览器中打开：

```
http://你的服务器IP:39921
```

将 `你的服务器IP` 替换为服务器的实际 IP 地址或主机名。

> 如果页面无法加载，请检查防火墙和云安全组是否已放行端口 **39921**。

## 第二步：创建管理员账户

首次访问时，Web.Casa 会自动跳转到 **初始设置页面**。你需要：

1. 设置 **管理员用户名**
2. 设置一个 **强密码**
3. 点击 **创建账户**

这将创建第一个拥有完整权限的管理员账户。

> 没有默认密码。第一个完成设置的用户将成为管理员。请在安装后立即完成此步骤，防止未授权访问。

## 第三步：熟悉仪表盘

登录后进入仪表盘，可查看服务器实时指标：

- **CPU** / **内存** / **磁盘** 使用率
- **网络** 吞吐量（入站和出站）
- 当前站点数量与运行状态
- Docker 容器概览（如已安装 Docker）

左侧导航栏提供所有功能模块入口 —— **站点**、**Docker**、**数据库**、**文件管理**、**终端**、**监控** 等。

## 第四步：创建第一个反向代理站点

1. 在左侧导航中点击 **站点**
2. 点击 **添加站点** 按钮
3. 选择 **反向代理** 作为站点类型
4. 填写配置信息：

| 字段 | 示例值 | 说明 |
|------|-------|------|
| **域名** | `app.example.com` | 你的域名 |
| **上游地址** | `127.0.0.1:3000` | 应用监听的地址 |

5. 点击 **保存**

> 保存前请确保域名的 **DNS A 记录** 已指向本服务器 IP。**Caddy** 会自动从 Let's Encrypt 获取 SSL 证书，站点将在数秒内以 HTTPS 方式上线。

## 第五步：启用 HTTPS（自动）

Web.Casa 使用 Caddy 内置的 ACME 客户端，满足以下条件时 HTTPS 自动生效：

- 域名 DNS 已解析到服务器公网 IP
- 端口 **80** 和 **443** 已放行

如需 **通配符证书**，请前往 **设置 > DNS 提供商**，配置 DNS 提供商凭据（Cloudflare、阿里云 DNS、腾讯云 DNS 或 Route53）。

## 第六步：加强安全

强烈建议完成以下安全配置：

1. **启用 TOTP 双因素认证** —— 前往 **设置 > 个人资料**，设置两步验证
2. **检查防火墙规则** —— 使用防火墙插件限制仅允许可信 IP 访问
3. **查看审计日志** —— 审计日志默认启用，可在 **设置 > 审计日志** 中查看
