Web.Casa 提供多种安装方式，您可以根据环境和需求选择最合适的方案。

<Tabs syncKey="install-method">
  <TabItem label="一键脚本" icon="terminal">
    最快捷的安装方式。安装脚本会自动检测操作系统、安装依赖并配置 Web.Casa。

    **支持的发行版（仅 EL9/EL10）：**
    - RHEL 9+
    - AlmaLinux 9+
    - Rocky Linux 9+
    - CentOS Stream 9+
    - Oracle Linux 9+
    - Fedora 38+
    - openAnolis 9+
    - 阿里云 Linux 3+
    - openEuler
    - openCloudOS 9+
    - 银河麒麟（Kylin）

    :::note
    预编译二进制文件要求 GLIBC >= 2.32。如果系统版本较旧，请使用 `--from-source` 参数在安装时进行源码编译。
    :::

    <Steps>
    1. **执行安装脚本**

       ```bash
       curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | sudo bash
       ```

    2. **访问面板**

       安装完成后，在浏览器中打开：

       ```
       http://您的服务器IP:39921
       ```

    3. **完成初始设置**

       按照页面提示创建管理员账户并配置初始设置。
    </Steps>
  </TabItem>

  <TabItem label="Docker" icon="seti:docker">
    使用内置的 Docker Compose 配置在容器中运行 Web.Casa。

    <Steps>
    1. **克隆仓库并启动容器**

       ```bash
       git clone https://github.com/web-casa/webcasa.git
       cd webcasa
       docker compose up -d
       ```

    2. **访问面板**

       在浏览器中打开：

       ```
       http://您的服务器IP:39921
       ```
    </Steps>
  </TabItem>

  <TabItem label="源码编译" icon="github">
    如果您需要完全控制构建过程，或系统不满足预编译二进制的 GLIBC 要求，可以选择从源码编译。

    **前置条件：**
    - Go 1.26+
    - Node.js 24+
    - GCC

    <Steps>
    1. **克隆仓库**

       ```bash
       git clone https://github.com/web-casa/webcasa.git
       cd webcasa
       ```

    2. **构建前端**

       ```bash
       cd web
       npm install
       npm run build
       cd ..
       ```

    3. **构建后端**

       ```bash
       go build -o webcasa .
       ```

    4. **启动服务**

       ```bash
       ./webcasa
       ```

       面板将在 `http://您的服务器IP:39921` 上可用。
    </Steps>

    :::tip
    您也可以使用一键脚本配合 `--from-source` 参数来自动完成源码编译：
    ```bash
    curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | sudo bash -s -- --from-source
    ```
    :::
  </TabItem>
</Tabs>

## 安装脚本参数

一键安装脚本支持以下参数：

| 参数 | 说明 |
| --- | --- |
| `--port PORT` | 设置自定义面板端口（默认：`39921`） |
| `--no-caddy` | 跳过 Caddy Web 服务器安装 |
| `--no-docker` | 跳过 Docker 用户组设置 |
| `--from-source` | 从源码编译而非使用预编译二进制文件 |
| `-y`、`--yes` | 非交互模式运行（自动接受所有默认值） |

**示例：** 使用自定义端口安装，并跳过 Caddy：

```bash
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | sudo bash -s -- --port 8080 --no-caddy
```

## 升级

将现有安装升级到最新版本：

```bash
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | sudo bash -s -- --upgrade
```

通过源码编译进行升级：

```bash
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | sudo bash -s -- --upgrade-from-source
```

## 卸载

**移除 Web.Casa 但保留数据：**

```bash
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | sudo bash -s -- --uninstall
```

`/var/lib/webcasa/` 和 `/etc/webcasa/webcasa.env` 中的数据和配置文件将被保留。

**完全移除 Web.Casa 及所有数据：**

```bash
curl -fsSL https://raw.githubusercontent.com/web-casa/webcasa/main/install.sh | sudo bash -s -- --purge
```

:::caution
`--purge` 参数会永久删除所有 Web.Casa 数据，包括站点配置和数据库。此操作不可撤销。
:::
