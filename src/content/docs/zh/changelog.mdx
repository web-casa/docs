## v0.9.3 (2026-03-01) — Web.Casa Pro

历经 10 个开发阶段，交付全功能服务器管理平台。

### 🧩 Phase 0：插件系统

- Go Interface 插件架构
- EventBus 跨插件事件通信
- ConfigStore 插件配置持久化
- CoreAPI 插件平台服务访问
- Frontend Manifests 前端扩展点

### 🐳 Phase 1：Docker 管理

- Compose Stack 管理（创建、启动、停止、删除）
- 容器生命周期控制
- 镜像拉取、标签管理、清理
- 网络与存储卷管理
- WebSocket 实时容器日志

### 🚀 Phase 2：项目部署

- Git 仓库支持（HTTPS 和 SSH）
- 11 个框架预设：Next.js、Nuxt、Vite、Remix、Express、Go、Laravel、Flask、Django、Dockerfile、Custom
- Systemd 服务生成与管理
- Webhook 自动化部署触发
- 版本回滚支持

### 🤖 Phase 3：AI 助手

- 兼容 OpenAI 的 LLM 集成，支持 SSE 流式传输
- 自动化错误诊断与建议
- Text-to-Compose：自然语言生成 Docker Compose
- AES-256-GCM 加密存储 API 密钥

### 📁 Phase 4：文件管理器 + Web 终端

- 树形导航与面包屑路径
- 文件上传、下载、压缩
- 基于 CodeMirror 的浏览器内代码编辑器
- xterm.js PTY 多标签终端

### 🗄️ Phase 5：数据库管理

- 一键创建 MySQL、PostgreSQL、MariaDB、Redis
- 数据库与用户 CRUD 操作
- 带语法高亮的 SQL 控制台
- SQLite 本地数据库浏览器

### 📊 Phase 6：备份 + 监控

- 基于 Kopia 的备份引擎，支持 Local、S3、WebDAV、SFTP
- Cron 定时调度与保留策略
- 实时 CPU、内存、磁盘、网络图表
- 容器资源监控
- WebSocket 指标流式推送
- 告警规则支持 Webhook 与邮件通知

### 🛒 Phase 7：应用商店

- 兼容 Runtipi 应用目录
- 一键安装与应用管理
- 多源仓库支持
- 项目模板快速脚手架

### 🔌 Phase 8：MCP Server + API Token

- 44 个 MCP 工具用于 IDE 集成
- `wc_` 前缀 API Token，SHA-256 哈希存储
- 支持 Cursor、Windsurf、Claude Code IDE 集成

### ✨ Phase 9：UX 优化

- 侧边栏精简为 4 个固定项加动态插件条目
- 设置页面整合
- 仪表盘卡片布局重设计
- i18n 修复与改进

### 🔒 安全加固

- AdminRouter JWT 鉴权
- API Token RBAC 授权
- MCP 基于 scope 的权限控制
- 路径穿越防护
- CORS 严格来源匹配
- AI 会话隔离
- WebSocket Origin 头校验
