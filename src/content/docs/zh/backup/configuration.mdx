Web.Casa 使用 **Kopia** 作为备份引擎。所有备份数据均经过 **密码加密** 后存储到指定目标。本页介绍存储配置、定时计划和保留策略。

## 前提条件

服务器上需要安装 Kopia CLI。如果尚未安装，Web.Casa 可以从面板中 **一键自动安装**。

> 有关安装和引擎机制的详情，请参阅 [Kopia 后端](/zh/backup/kopia/) 页面。

## 存储目标

Web.Casa 支持四种存储目标类型：

| 目标 | 适用场景 |
|------|----------|
| **本地文件系统** | 备份到服务器的另一块磁盘、分区或挂载的外部驱动器 |
| **S3 / MinIO** | 云端对象存储（Amazon S3、MinIO、Backblaze B2、Wasabi 等） |
| **WebDAV** | 通过 Nextcloud、NAS 设备或任何 WebDAV 服务器的网络存储 |
| **SFTP** | 通过 SSH 连接的远程服务器 |

### S3 / MinIO 配置

- **端点 URL** -- S3 兼容的 API 端点
- **存储桶名称** -- 目标存储桶
- **Access Key** 和 **Secret Key** -- API 凭据
- **区域**（可选）

### SFTP 配置

- **主机** 和 **端口** -- 远程服务器地址
- **用户名** -- SSH 登录用户
- **认证方式** -- 密码 **或** SSH 私钥路径
- **远程路径** -- 远程服务器上用于存储备份的目录

### WebDAV 配置

- **URL** -- 完整的 WebDAV 端点
- **用户名** 和 **密码**

### 本地文件系统配置

- **路径** -- 服务器上的绝对目录路径

## 加密

所有备份数据均使用初始配置时设定的 **仓库密码** 加密。

> **此密码是解密备份的唯一凭据。** 请将其保存在独立的安全位置。密码丢失后，备份数据将无法恢复。

## 备份范围

选择每次备份要包含的数据：

| 范围 | 备份内容 |
|------|----------|
| **面板** | Web.Casa 数据库和 Caddyfile 配置 |
| **Docker 卷** | Web.Casa 管理的所有 Docker 卷 |
| **数据库转储** | 所有数据库实例的 SQL 导出 |

每个备份配置可启用一个或多个范围。

## 定时计划

备份使用 **Cron 表达式** 配置定时计划。面板提供常用计划预设：

| 预设 | Cron 表达式 | 说明 |
|------|-------------|------|
| 每天凌晨 2:00 | `0 2 * * *` | 每天 02:00 执行 |
| 每天凌晨 4:00 | `0 4 * * *` | 每天 04:00 执行 |
| 每周日凌晨 3:00 | `0 3 * * 0` | 每周日 03:00 执行 |

也可以输入 **自定义 Cron 表达式** 设置其他计划。

## 保留策略

控制保留多少快照以及保留多长时间：

| 设置 | 说明 |
|------|------|
| **保留最近 N 个快照** | 始终保留最近的 N 个快照 |
| **保留 N 天** | 保留最近 N 天内创建的快照 |

> 建议起步配置：保留 **最近 10 个快照**，保留期限 **30 天**。

## 状态与监控

备份仪表板显示每个备份配置的当前状态：

- **状态** -- `空闲` 或 `运行中`
- **上次备份** -- 最近一次完成备份的时间戳
- **下次计划** -- 下次备份的执行时间

可随时通过 **立即运行** 按钮触发 **手动备份**。
