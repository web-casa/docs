**Kopia** 是驱动 Web.Casa 备份系统的开源备份引擎，提供加密、去重、增量备份能力。

## 安装

备份功能需要安装 Kopia CLI。Web.Casa 提供两种安装方式：

1. **面板一键安装** -- 在 **备份 > 设置** 中点击安装按钮，Web.Casa 将自动下载并配置 Kopia。
2. **手动安装** -- 通过系统包管理器或从 [Kopia 官方发布页](https://github.com/kopia/kopia/releases) 自行安装 Kopia CLI。

> 安装完成后，Web.Casa 会自动检测 Kopia 二进制文件，无需额外的路径配置。

## 工作原理

Kopia 采用 **内容寻址存储** 模型：

1. 文件被拆分为 **基于内容定义的数据块**。
2. 每个数据块在存储前经过 **压缩** 和 **加密**。
3. 相同内容的数据块只存储一份（**去重**）。
4. 后续备份仅传输 **新增或变更的数据块**（增量）。

这种架构使得备份快速且存储高效，即使面对大规模数据集也是如此。

## 仓库

**仓库**（Repository）是存储所有备份数据的加密容器。在首次配置备份目标时完成初始化。

**支持的仓库后端：**

| 后端 | 说明 |
|------|------|
| **本地文件系统** | 本地或挂载磁盘上的目录 |
| **S3 / MinIO** | S3 兼容的对象存储 |
| **WebDAV** | 网络附加存储或云盘 |
| **SFTP** | 通过 SSH 连接的远程服务器 |

> 各目标的详细配置说明请参阅 [备份配置](/zh/backup/configuration/) 页面。

## 加密

- 所有备份数据使用 **AES-256-GCM** 进行静态加密
- 加密在数据 **离开服务器之前** 完成
- **仓库密码** 在初始化时设定，后续所有访问都需要此密码

> **请将仓库密码保存在独立的安全位置。** 如果无法访问 Web.Casa，您需要此密码通过 Kopia CLI 直接恢复备份。密码没有恢复机制。

## 仓库管理

在 Web.Casa 面板中，可以监控和维护仓库：

- **仓库统计** -- 总大小、快照数量、去重比率
- **完整性验证** -- 校验存储数据是否损坏
- **维护任务** -- 压缩和垃圾回收以释放空间

## 与 Web.Casa 的集成

Kopia 完全通过 Web.Casa 界面管理。面板负责：

- **仓库初始化** 和连接
- 按计划或按需 **创建快照**
- 根据配置的策略 **执行保留规则**
- 从任何可用快照进行 **恢复操作**

除非进行高级故障排查，否则无需直接操作 Kopia CLI。
