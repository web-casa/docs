title: 恢复
description: 从备份快照中恢复数据，管理快照生命周期

Web.Casa 提供基于快照的恢复界面。浏览可用快照、检查内容，并通过确认流程防止意外覆盖。

## 快照管理

### 查看快照

进入 **备份** 页面即可查看所有可用快照。每个快照显示以下信息：

- **快照 ID** -- 唯一标识符
- **创建时间** -- 备份执行的时间
- **备份范围** -- 快照包含的数据类型（面板、Docker 卷、数据库转储）

### 筛选快照

当快照列表较长时，使用 **按 ID 筛选** 字段搜索特定快照。

### 删除快照

1. 选择要删除的快照。
2. 点击 **删除**。
3. 确认操作。

> 已删除的快照无法恢复。请仅删除确认不再需要的快照。

## 从快照恢复

### 操作步骤

1. 进入 **备份 > 恢复** 页面。
2. 选择要恢复的快照。
3. 查看快照内容。
4. 点击 **恢复**。
5. 仔细阅读 **确认对话框** -- 其中会警告现有数据将被 **覆盖**。
6. 确认后开始恢复过程。

> **恢复操作会覆盖当前数据。** 请确保选择了正确的快照，并了解哪些文件将被替换。

### 恢复内容

恢复范围取决于原始备份中包含的内容：

| 备份范围 | 恢复内容 |
|----------|----------|
| **面板** | Web.Casa 数据库和 Caddyfile 配置 |
| **Docker 卷** | Docker 卷数据恢复到原始位置 |
| **数据库转储** | 可重新导入数据库实例的 SQL 转储文件 |

## 快照日志

每个快照都有关联的 **日志**，记录备份操作的详细信息：

- **级别** -- 信息、警告或错误
- **时间戳** -- 日志条目的创建时间
- **消息** -- 操作描述或问题说明

选择快照并查看其 **日志** 选项卡即可访问日志。这对于诊断失败或不完整的备份非常有用。

## 最佳实践

- **定期测试恢复** -- 在需要紧急恢复之前，先验证备份是否确实可用
- 每次备份后 **检查快照日志** 以确认成功
- **保留多个快照**，以便选择合适的恢复点
- **记录备份范围**，明确每个快照包含的具体内容
