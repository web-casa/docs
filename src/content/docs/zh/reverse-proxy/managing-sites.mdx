---
title: 站点管理
description: 创建、编辑和管理反向代理站点，包括上游服务器、负载均衡和自定义头
---

所有站点管理操作都在 Web.Casa 面板的**反向代理**模块中进行。配置变更通过 Caddy Admin API 即时生效，零停机。

## 创建站点

1. 点击**添加站点**。
2. 选择**站点类型**：反向代理、重定向、静态站点 或 PHP 站点。
3. 输入**域名**（如 `app.example.com`）。
4. 根据站点类型配置相应参数（详见下方各节）。
5. 选择 **TLS 模式**（默认为自动）。
6. 点击**保存**。

> 你也可以从**模板**开始 -- 选择预设模板（WordPress、SPA、API、PHP-FPM、静态文件服务器、WebSocket），Web.Casa 会自动预填配置。

## 各站点类型配置

### 反向代理

- **上游服务器** -- 一个或多个后端地址，格式为 `host:port`（如 `127.0.0.1:3000`、`backend:8080`）
- **负载均衡** -- 流量通过 **Round Robin** 策略分发到各上游
- 支持 HTTP 和 HTTPS 上游协议

### 重定向

- **目标 URL** -- 访客将被发送到的目标地址
- **状态码** -- 选择 **301**（永久）或 **302**（临时）
- **原始 URI 路径**会自动附加到目标 URL

### 静态站点

- **根目录** -- 文件所在的服务器路径（如 `/var/www/mysite`）
- **索引文件** -- 可配置索引文件名（如 `index.html`、`index.htm`）
- **目录浏览** -- 当没有索引文件时，可选启用文件列表展示

### PHP 站点

- **根目录** -- PHP 应用文件的路径
- **FastCGI 端点** -- 通过 `localhost:9000` 或 **Unix Socket** 路径连接 PHP-FPM
- 适用于 WordPress、Laravel 及任何 PHP-FPM 应用

## WebSocket 支持

为站点启用 **WebSocket 代理**，将 WebSocket 连接透传到上游服务器。这对于聊天、实时仪表盘、协作编辑等实时应用至关重要。

## 压缩

启用响应压缩以减少带宽、提升加载速度：

- **Gzip** -- 所有浏览器广泛支持
- **Zstd** -- 更高压缩比、更低 CPU 开销（现代浏览器支持）

两者可同时启用，Caddy 会根据客户端自动协商最佳编码。

## 安全头

一键启用常见安全头：

| 头信息 | 作用 |
|--------|------|
| `X-Frame-Options` | 防止点击劫持，控制 iframe 嵌入 |
| `X-Content-Type-Options` | 阻止浏览器进行 MIME 类型嗅探 |
| `X-XSS-Protection` | 启用浏览器内置 XSS 过滤器 |

## CORS 跨域资源共享

为每个站点配置 CORS 规则：

- **允许的来源** -- 指定哪些域名可以发起跨域请求
- **允许的方法** -- `GET`、`POST`、`PUT`、`DELETE` 等
- **允许的头信息** -- 客户端可发送的自定义头

> CORS 配置对于被不同域名前端应用调用的 API 站点至关重要。

## 自定义错误页面

用自定义 HTML 页面替换 Caddy 默认的错误响应：

- **404** -- 页面未找到
- **500** -- 服务器内部错误
- 任何其他 HTTP 状态码

上传或引用错误页面文件，Web.Casa 会自动配置 Caddy 提供服务。

## 自定义 Caddyfile 指令

对于 UI 未覆盖的高级用例，可以向站点配置块中直接注入**原始 Caddyfile 指令**，完整访问 Caddy 的指令库。

> 请谨慎使用 -- 无效的指令可能导致站点配置错误。Web.Casa 会在应用前进行语法验证。

## HTTP Basic Auth

使用用户名/密码保护站点：

1. 在站点设置中启用 **Basic Auth**。
2. 添加一个或多个用户账户。
3. 密码使用 **bcrypt** 加密存储。

浏览器将在访客访问前提示输入凭据。

## IP 访问控制

基于客户端 IP 地址限制站点访问：

- **白名单模式** -- 仅允许列出的 IP/CIDR 访问，其他全部拒绝
- **黑名单模式** -- 拒绝列出的 IP/CIDR 访问，其他全部允许

地址使用 **CIDR 表示法**（如 `192.168.1.0/24`、`10.0.0.1/32`、`2001:db8::/32`）。

## HTTP 到 HTTPS 重定向

为站点启用**自动 HTTP 到 HTTPS 重定向**。启用后，所有 80 端口的请求将以 301 状态码重定向到 HTTPS 地址。

## 分组和标签

组织站点以便于管理：

- **分组** -- 将站点分配到命名分组（如"生产环境"、"预发布"、"内网"）
- **标签** -- 添加自由标签，用于筛选和搜索

分组和标签显示在站点列表中，可用于快速过滤大量站点。

## 站点克隆

复制现有站点配置：

1. 打开要克隆的站点。
2. 点击**克隆**。
3. 输入新的**域名**。
4. 根据需要调整设置。
5. 保存新站点。

所有设置（上游、TLS 模式、头信息、访问规则）都会复制到新站点。

## DNS 检查

在上线前，使用内置 **DNS 检查**功能验证域名的 **A** 和 **AAAA** 记录是否指向服务器 IP。这有助于在证书签发失败或停机前发现 DNS 配置错误。

## 编辑和删除站点

- 点击列表中的任意站点即可打开设置并编辑任何字段。
- 变更**即时生效** -- 无需重启。
- **删除**站点会同时从数据库和 Caddy 运行配置中移除。
- 使用**启用/禁用开关**可临时下线站点，而不会丢失配置。
