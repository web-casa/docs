Web.Casa 通过存储在 `/etc/webcasa/webcasa.env` 中的**环境变量**进行配置。通过 Web 界面管理的设置（主机、用户、插件）存储在 SQLite 数据库中。

## 环境配置文件

主配置文件位于：

```
/etc/webcasa/webcasa.env
```

> **需要重启：** 修改环境变量后，需执行 `systemctl restart webcasa` 重启服务使变更生效。

## 环境变量

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `WEBCASA_PORT` | `39921` | 面板监听端口 |
| `WEBCASA_DATA_DIR` | `./data` | 数据目录，存放数据库、证书和备份 |
| `WEBCASA_DB_PATH` | `data/webcasa.db` | SQLite 数据库文件路径 |
| `WEBCASA_JWT_SECRET` | 自动生成 | JWT 认证令牌的签名密钥。未设置时自动生成并持久化到 `data/.jwt_secret` |
| `WEBCASA_CADDY_BIN` | `caddy` | Caddy 二进制文件路径 |
| `WEBCASA_CADDYFILE_PATH` | `data/Caddyfile` | 生成的 Caddyfile 路径 |
| `WEBCASA_LOG_DIR` | `data/logs` | 日志文件目录 |

> **说明：** 如未设置 `WEBCASA_JWT_SECRET`，Web.Casa 会自动生成随机密钥并持久化到 `data/.jwt_secret`。您也可以通过显式设置环境变量来覆盖，建议使用高强度随机字符串（推荐 32 个字符以上）。

## 配置优先级

Web.Casa 按以下顺序读取配置（后者覆盖前者）：

1. **内置默认值**
2. **环境配置文件**（`/etc/webcasa/webcasa.env`）
3. **环境变量**（在 shell 或 systemd 单元中设置）

只需指定需要修改的值，其余使用默认值即可。

## 面板设置

以下设置通过 Web 界面的**设置**页面管理：

- **自动重载 Caddy** -- 配置变更后自动应用到 Caddy，无需手动重载
- **服务器 IP 配置** -- 设置服务器的公网 IP，用于 DNS 和证书操作
- **导入/导出** -- 以 JSON 格式备份和恢复面板配置
- **Caddyfile 编辑器** -- 内置代码编辑器，基于 **CodeMirror 6**，支持：
  - 语法高亮
  - **格式化** -- 自动格式化 Caddyfile
  - **验证** -- 检查配置错误
  - **保存** -- 持久化变更
  - **重载** -- 将变更应用到运行中的 Caddy 实例

## 关键文件路径

| 路径 | 用途 |
|------|------|
| `/etc/webcasa/webcasa.env` | 环境配置文件 |
| `/var/lib/webcasa/webcasa.db` | SQLite 数据库（WAL 模式） |
| `/var/lib/webcasa/` | 数据目录（证书、备份、上传文件） |

## 数据库中的配置

以下设置通过 Web 界面管理，存储在 SQLite 中而非配置文件：

- 反向代理主机定义
- DNS 提供商凭据
- 用户账户和角色
- 证书记录
- 备份计划
- 插件特定设置
- 审计日志条目
