> **注意：** 镜像管理功能现已整合到 **Docker 概览**页面中，不再作为独立页面存在。以下内容描述了可从 Docker 概览页面访问的所有镜像管理功能。

镜像管理模块提供完整的 Docker 镜像管理界面 -- 从 Docker Hub 拉取新镜像到清理未使用镜像释放磁盘空间。

## 镜像列表

镜像面板展示所有本地镜像的关键信息：

| 列 | 说明 |
|----|------|
| **仓库** | 镜像名称和标签（如 `nginx:alpine`） |
| **镜像 ID** | 唯一 SHA256 标识符 |
| **大小** | 占用磁盘空间 |
| **创建时间** | 镜像构建时间 |

- **按大小排序**，快速找出占用空间最多的镜像
- **搜索** 镜像名称或标签，精确定位目标镜像
- 正在被容器使用的镜像会有明确标识

## 拉取镜像

### 从 Docker Hub 拉取

1. 点击 **拉取镜像**。
2. 输入镜像名称和可选标签（如 `nginx:latest`、`postgres:16-alpine`）。
3. 点击 **拉取**。

下载过程实时展示，显示每一层的下载和解压状态。

### 搜索 Docker Hub

Web.Casa 内置 **Docker Hub 搜索** 功能：

1. 点击 **搜索** 或在拉取对话框中使用搜索栏。
2. 输入关键词（如 `redis`、`mysql`）。
3. 浏览搜索结果，包含镜像名称、描述、星标数和官方标识。
4. 点击结果上的 **拉取** 按钮直接下载。

> 如果位于中国大陆且拉取速度较慢，请在 Docker 守护进程设置中配置 **镜像加速器**。Web.Casa 提供国内常用加速器的一键预设。

## 从镜像运行容器

在镜像列表中可以直接启动容器：

1. 点击任意镜像上的 **运行** 操作。
2. 容器创建表单将自动填入所选镜像。
3. 配置端口、卷、环境变量等设置。
4. 点击 **创建** 启动容器。

---

## 清理未使用镜像

随着时间推移，未使用的镜像会不断累积并占用磁盘空间。Web.Casa 提供 **清理** 功能来处理这些镜像：

1. 点击 **清理未使用镜像**。
2. 查看将被删除的镜像列表（未被任何容器引用的镜像）。
3. 确认后释放磁盘空间。

清理操作会报告：

- **删除的镜像数量**
- **回收的磁盘空间总量**

> 清理仅移除 **未被任何容器使用** 的镜像（包括运行中和已停止的容器）。不会影响正在使用的服务。

## 镜像操作

| 操作 | 说明 |
|------|------|
| **拉取** | 从仓库下载镜像 |
| **运行** | 从镜像创建并启动容器 |
| **删除** | 从本地移除镜像 |
| **清理** | 批量移除所有未使用镜像 |

> 删除正在被运行中或已停止容器使用的镜像时，会触发确认警告，防止影响现有服务。

## 仓库配置

通过 Docker 守护进程设置（**Docker > 设置**）可以配置：

### 镜像加速

添加镜像加速器 URL 以提升拉取速度。预置选项包括：

- **国内镜像预设** -- 阿里云、腾讯云、中科大等常用国内加速器，一键配置

### 非安全仓库

对于使用 HTTP 而非 HTTPS 的私有仓库：

1. 进入 **Docker > 设置 > 非安全仓库**。
2. 添加仓库地址（如 `192.168.1.100:5000`）。
3. 保存并在提示时重启 Docker 守护进程。
