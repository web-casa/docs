网络和卷是 Docker 部署的基础构建单元。Web.Casa 提供专门的管理界面，用于创建、查看和删除这两类资源。

---

## 网络

Docker 网络实现 **容器间通信**。同一网络中的容器可以通过名称互相访问。

### 网络列表

网络面板展示所有 Docker 网络的信息：

| 列 | 说明 |
|----|------|
| **名称** | 网络名称 |
| **驱动** | 网络驱动类型 |
| **作用域** | `local` 或 `swarm` |
| **创建时间** | 创建时间戳 |

### 创建网络

1. 点击 **创建网络**。
2. 配置以下选项：

| 设置 | 说明 |
|------|------|
| **名称** | 描述性的网络名称 |
| **驱动** | `bridge`（默认）、`host`、`overlay`、`macvlan` 或 `none` |
| **子网** | IP 子网（如 `172.20.0.0/16`） |
| **网关** | 网关 IP 地址 |
| **IP 范围** | 子网内可分配的 IP 范围 |
| **驱动选项** | 额外的驱动特定键值设置 |

3. 点击 **创建**。

**常用驱动类型：**

- **bridge** -- 单主机最常用的选择；同一 bridge 网络内的容器可通过名称通信
- **host** -- 容器直接共享主机网络栈（无需端口映射）
- **overlay** -- 用于 Docker Swarm 的多主机通信
- **macvlan** -- 为容器分配 MAC 地址，使其在网络中表现为物理设备

> 为不同的应用栈使用独立的 bridge 网络可以实现 **网络隔离**。例如，将数据库容器放在私有网络中，只允许应用容器访问。

### 删除网络

选择一个或多个网络并点击 **删除**。如果有容器连接到该网络，Web.Casa 会发出警告。

> Docker 的默认网络（`bridge`、`host`、`none`）不能删除，只有用户创建的网络可以移除。

## 卷

Docker 卷提供 **持久化数据存储**，数据在容器重启和删除后仍然保留。

### 卷列表

卷面板展示所有 Docker 卷的信息：

| 列 | 说明 |
|----|------|
| **名称** | 卷名称 |
| **驱动** | 存储驱动（通常为 `local`） |
| **挂载点** | 数据在主机上的文件系统路径 |

### 创建卷

1. 点击 **创建卷**。
2. 配置：
   - **名称** -- 描述性的卷名称
   - **驱动** -- 存储驱动（默认：`local`）
   - **驱动选项** -- 如需额外的键值选项
3. 点击 **创建**。

### 卷操作

| 操作 | 说明 |
|------|------|
| **查看挂载点** | 查看数据在主机文件系统上的存储路径 |
| **删除** | 移除卷及其数据 |

> **警告：** 删除卷将永久销毁其数据。删除前请务必确认该卷不再需要，建议先备份重要数据。

### 卷的使用场景

卷是以下场景中推荐的数据持久化方式：

- **数据库存储** -- PostgreSQL、MySQL、MongoDB 的数据目录
- **上传目录** -- 需要持久保存的用户上传文件
- **配置文件** -- 容器更新后仍需保留的持久配置
- **共享数据** -- 需要被多个容器访问的文件

## 与 Compose 配合

部署 **Compose Stack** 时，Compose 文件中定义的网络和卷会自动创建：

```yaml
services:
  app:
    networks:
      - frontend
      - backend
    volumes:
      - app-data:/data

  db:
    networks:
      - backend
    volumes:
      - db-data:/var/lib/postgresql/data

networks:
  frontend:
  backend:
    internal: true  # 禁止外部访问

volumes:
  app-data:
  db-data:
```

这些资源会出现在网络和卷管理界面中，可以独立于 Compose Stack 进行查看。

> **警告：** 删除属于活跃 Compose Stack 的网络或卷可能导致服务中断。如需修改资源，请先停止 Stack。
