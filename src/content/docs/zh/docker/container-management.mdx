Web.Casa 提供完整的 Docker 容器生命周期管理和 Compose 编排功能，通过直观的 Web 界面即可完成所有操作。

## 安装 Docker

如果服务器尚未安装 Docker，Web.Casa 可以直接在面板中完成安装。

1. 在侧边栏中进入 **Docker** 模块。
2. 点击 **安装 Docker**。
3. 选择安装源：
   - **默认** -- 从 Docker 官方仓库安装
   - **国内镜像（DaoCloud）** -- 推荐中国大陆服务器使用，显著提升下载速度

> 安装完成后，Docker 管理界面立即可用，无需额外手动配置。

## 容器列表

容器面板展示 **所有运行中和已停止的容器**，关键信息一目了然：

| 列 | 说明 |
|----|------|
| **名称** | 容器名称（点击进入详情） |
| **镜像** | 使用的镜像和标签 |
| **状态** | 运行中、已停止、已暂停或已退出 |
| **端口** | 主机到容器的端口映射 |
| **CPU / 内存** | 实时资源消耗 |
| **创建时间** | 容器创建时间戳 |

- 使用 **搜索栏** 按容器名称或镜像进行筛选
- 由应用商店管理的容器会标记为 **应用商店托管**

## 运行新容器

点击 **运行容器** 启动新容器，支持以下配置项：

### 基本设置

- **名称** -- 自定义容器名称
- **镜像** -- 从本地镜像中选择或拉取新镜像
- **重启策略** -- 可选 `no`、`always`、`on-failure` 或 `unless-stopped`
- **网络** -- 将容器接入已有的 Docker 网络
- **命令覆盖** -- 覆盖默认的入口点或 CMD 命令

### 端口映射

将主机端口映射到容器端口：

```
主机端口 : 容器端口 / 协议
8080     : 80       / TCP
```

可添加多条映射规则，适用于暴露多个端口的服务。

### 卷挂载

将主机目录或命名卷绑定到容器内路径：

```
/host/path/data  →  /container/path/data
my-named-volume  →  /var/lib/data
```

### 环境变量

以 **键值对** 形式定义环境变量，在容器启动时注入。

### 资源限制

| 设置 | 说明 |
|------|------|
| **内存限制** | 最大内存（MB），例如 `512` |
| **CPU 限制** | CPU 百分比或核心数 |

> 设置资源限制可防止单个容器耗尽服务器资源，在多租户或共享环境中尤为重要。

## 容器操作

每个容器支持以下操作：

| 操作 | 说明 |
|------|------|
| **启动** | 启动已停止的容器 |
| **停止** | 优雅停止运行中的容器 |
| **重启** | 停止后立即重新启动 |
| **日志** | 查看实时 stdout/stderr 输出，支持时间筛选 |
| **监控** | 实时查看 CPU、内存和网络 I/O |
| **删除** | 删除容器（需确认） |

### 查看日志

日志查看器提供：

- **实时流式输出**，随容器运行持续更新
- **时间戳显示**，精确定位每条日志
- 支持 **历史回溯** 或 **跟踪最新** 输出

### 资源监控

监控面板展示实时指标：

- **CPU 使用率** -- 已分配 CPU 的使用百分比
- **内存使用** -- 当前消耗 vs. 限制值
- **网络 I/O** -- 发送和接收的字节数

## Compose 编排

Docker Compose 可以将 **多容器应用** 作为一个整体来定义和管理。

### 创建 Stack

1. 点击 **创建 Stack**。
2. 输入 **Stack 名称**。
3. 在 **Compose 编辑器** 中编写或粘贴 `docker-compose.yml` 内容。
4. 点击 **部署** 启动所有服务。

Web.Casa 会在部署前验证 Compose 文件结构，发现语法错误时会立即提示。

### 管理 Stack

部署完成后，每个 Stack 支持：

- **启动 / 停止 / 重启** -- 统一控制 Stack 内所有服务
- **Stack 日志** -- 聚合查看所有服务的日志流
- **编辑并重新部署** -- 修改 Compose 文件后一键更新

### Compose 文件示例

```yaml
version: "3.8"
services:
  web:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./html:/usr/share/nginx/html
    restart: unless-stopped

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - pgdata:/var/lib/postgresql/data
    restart: unless-stopped

volumes:
  pgdata:
```

> Compose Stack 非常适合部署包含 Web 服务器、应用后端、数据库和缓存层的完整应用环境。

## Docker 守护进程设置

Web.Casa 通过 UI 暴露了关键的 Docker 守护进程配置选项：

### 镜像加速

通过配置镜像加速器提升镜像拉取速度：

- 添加自定义镜像源 URL
- **国内镜像预设** -- 一键配置阿里云、腾讯云、中科大等常用国内加速器

### 非安全仓库

注册使用 HTTP 而非 HTTPS 的私有仓库，将仓库地址添加到非安全仓库列表即可。

### 日志配置

| 设置 | 说明 |
|------|------|
| **日志驱动** | `json-file`、`syslog`、`journald` 等 |
| **最大大小** | 单个日志文件的最大体积（如 `10m`） |
| **最大文件数** | 保留的轮转日志文件数量 |

### 其他设置

- **存储驱动** -- 配置 Docker 存储后端
- **实时恢复（Live Restore）** -- Docker 守护进程重启时保持容器运行

> 修改守护进程设置需要重启 Docker 守护进程。Web.Casa 会在应用更改前要求确认。

## 前置要求

- 主机上必须安装 **Docker**（可通过面板直接安装）
- 在 Docker 中运行 Web.Casa 时，请确保挂载了 `/var/run/docker.sock` 卷
