## v1.0.0 (2026-03-01) — Web.Casa Pro

10 development phases completed, delivering a full-featured server management platform.

### Phase 0: Plugin System

- Go Interface-based plugin architecture
- EventBus for inter-plugin communication
- ConfigStore for persistent plugin configuration
- CoreAPI for plugin access to platform services
- Frontend Manifests for UI extension points

### Phase 1: Docker Management

- Compose Stack management (create, start, stop, remove)
- Container lifecycle controls
- Image pull, tag, and cleanup
- Network and Volume management
- Real-time WebSocket container logs

### Phase 2: Project Deployment

- Git repository support (HTTPS and SSH)
- 9 framework presets: Next.js, Nuxt, Vite, Remix, Express, Go, Laravel, Flask, Django
- Systemd service generation and management
- Webhook triggers for automated deployment
- Version rollback support

### Phase 3: AI Assistant

- OpenAI-compatible LLM integration with SSE streaming
- Automated error diagnosis and suggestions
- Text-to-Compose: natural language to Docker Compose generation
- AES-256-GCM encryption for API key storage

### Phase 4: File Manager + Web Terminal

- Tree navigation with breadcrumb paths
- File upload, download, and compression
- CodeMirror-based in-browser code editor
- xterm.js PTY with multi-tab terminal support

### Phase 5: Database Management

- One-click creation for MySQL, PostgreSQL, MariaDB, and Redis
- Database and User CRUD operations
- SQL console with syntax highlighting
- SQLite browser for local database files

### Phase 6: Backup + Monitoring

- Kopia-based backup engine with Local, S3, WebDAV, and SFTP targets
- Cron scheduling and retention policies
- Real-time CPU, memory, disk, and network charts
- Container resource monitoring
- WebSocket-based metrics streaming
- Alert rules with Webhook and Email notifications

### Phase 7: App Store

- Runtipi-compatible app catalog
- One-click application install and management
- Multi-source repository support
- Project templates for quick scaffolding

### Phase 8: MCP Server + API Token

- 18 MCP tools for IDE integration
- `wc_` prefixed API tokens with SHA-256 hashing
- Cursor, Windsurf, and Claude Code IDE integration support

### Phase 9: UX Polish

- Sidebar simplified from 13 to 8 items
- Settings page consolidation
- Dashboard card layout redesign
- i18n fixes and improvements

### Security Hardening

- AdminRouter JWT authentication
- API Token RBAC authorization
- MCP scope-based permissions
- Path traversal protection
- CORS strict origin matching
- AI session isolation
- WebSocket Origin header validation
